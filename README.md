## Proyectos

### 🧪 [Testing Funcional y Exploratorio — Swag Labs (SauceDemo)](./saucedemo-testing/README.md)
Testing manual de un e-commerce de práctica: diseñé 10 casos de prueba sobre login, catálogo, carrito y checkout, ejecutados contra 4 perfiles de usuario distintos. Encontré y documenté **3 bugs reproducibles** con severidad y pasos de reproducción, incluyendo uno crítico que bloquea por completo el checkout.

**Resultado clave:** 7/10 casos pasaron; 3 fallaron con bugs documentados (uno de severidad crítica).

### 🔌 [Testing de API — ReqRes (CRUD de usuarios)](./api-testing-reqres/README.md)
Testing funcional de una API REST: diseñé y ejecuté 8 casos de prueba cubriendo las 4 operaciones CRUD (GET, POST, PUT, DELETE) más casos límite, verificando códigos de estado HTTP reales y estructura de respuesta.

**Resultado clave:** 7/8 casos pasaron; identifiqué una falta de validación de campos requeridos en la creación de usuarios.
